    Three unrelated sets of threads: V8's own GC/JIT helpers, libuv's process‑global pool of 4, and any worker threads you spawn. Only worker threads run your JavaScript.

    Processes & cluster: the strongest boundary

    Worker threads share one process, so a native fault or OOM takes them all down. To use every CPU core for a network server with a real failure boundary, you run multiple processes instead, via child_process / cluster. Each is a separate Node.js instance with its own heap and GC.
